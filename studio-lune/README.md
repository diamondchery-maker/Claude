# Studio Lune (tattoo artist demo)

A demo portfolio site for a fine line / dotwork tattoo artist. The name, work, prices and contact details are placeholders to swap out once the real artist's info is in.

- `index.html`: standalone page. Open it in a browser (it needs internet for Google Fonts, GSAP and Lenis).
- `page.html`: the same page without the `<html>/<head>/<body>` wrapper, used for the claude.ai artifact.

Features: WebGL ink shader hero that follows the cursor, the artist's name "drawn" by a needle stroke, scroll-velocity marquee, scroll-lit manifesto, a pinned horizontal gallery of generated flash art with a view-transition lightbox, hover image previews, a custom blend-mode cursor, magnetic buttons, Lenis smooth scroll, and a booking form with a live price estimate. Respects `prefers-reduced-motion`.
