# Rust Avenue

A side-scrolling street brawler in the spirit of Streets of Rage 4. It's a single self-contained `index.html` (canvas + Web Audio, no build step). Open the file in a browser to play.

## Controls

| Action | Keyboard |
| --- | --- |
| Move | Arrows / WASD |
| Attack (mash for a 4-hit combo) | J or Z |
| Jump (attack in the air for a flying kick) | K, X or Space |
| Special (costs health you win back by landing hits) | L or C |
| Run / dash attack | Double-tap a direction, then attack |
| Grab | Walk into an enemy |
| Knee / throw | While holding: J to knee, back + J to throw |
| Pause / music | P / M |

Touch devices get an on-screen joystick and buttons.

## What's in it

- Four enemy types: thugs, knife fighters, armored brutes, and Baron, the boss, with a jab combo, a charging tackle and a ground-slam shockwave.
- Five locked-screen waves along one street, ending at the harbor.
- Breakable barrels and trash cans that drop apples, roast chicken, cash, and lead pipes.
- Hit-stop, screen shake, knockdowns with bounce, thrown enemies that bowl over others, and a combo counter.
- Synthesized sound effects and a house-style music loop.
